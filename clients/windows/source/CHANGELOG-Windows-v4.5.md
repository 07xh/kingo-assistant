# Windows V4.5｜内置离线演练、错误分类、源码启动可靠性

日期：2026-11-11

## 新增与修复

- 新增 `core/demo.py` 和 `demo/` 三步**虚构**课程快照：满额 → 有余量 → 再次满额；每次点击“虚构样例：下一步”推进一帧，第三次后可重新开始。演示不建立学校 HTTP 会话、不访问网络、不写提醒状态文件。
- 真实配置与虚构样例彻底分离：点击“检查配置”恢复用户配置，启动真实只读监测前重新读取并验证本机配置。
- EXE 打包命令和 GitHub Actions 均加入 `demo/` 资源；打包后 `--self-test` 验证虚构资源完整且发生预期的“有余量”状态转移。
- `Scheduler` 新增不包含服务器页面或凭据的故障原因：会话失效、403/429 频率/访问限制、页面协议不符、网络请求失败、本机配置错误。GUI 将原因显示为“已停止”。
- `run-windows.bat` 兼容 Windows 上的 `py -3` 或 `python`，并检测已有虚拟环境是否缺少依赖，必要时重新安装。
- 新增 8 项回归测试，原先 58 项增加到 **66 项**，涵盖故障分类和无网络虚构样例；通过 Xvfb/Tk 交互烟雾测试。
