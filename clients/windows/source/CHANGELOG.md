## V4.1 — 编码一致性、提醒确认与离线输入安全

- 离线回归测试 40/40 通过；无学校实测。

- 严格区分显式声明的 UTF-8 与 GB18030，字符编码冲突/无法解码时停止读取。
- 推送确认必须是明确 JSON 成功码；非布尔真值不得消费下一次提醒。
- 拒绝单文件回放的符号链接，与多文件回放共用读取约束。
- 不增加真实选课写入、高频监测或验证码处理。
