# KingoAssistant Windows V5.0 — 本地流程和受限只读监测优化

## 本轮实际实现

- **离线空方案**：`courses: []` 可以保存、切换与编辑；一旦开始真实监测，仍必须有 1–30 门真实目标课程。配置草稿不再因学校协议未完成验证而无法编辑。
- **按时长持续监测**：`strategy.max_cycles: 0` 表示不以次数停止，但 `strategy.max_duration_minutes` 始终生效（1–1440 分钟）。原 100 次硬上限改为最多 10,000 次。也支持手动停止。
- **查询频率规则**：无可靠规则时默认不低于 60 秒；如确已阅读学校官方允许的频率政策，可手工登记 `official_frequency_policy.manually_confirmed: true`、`source`、`min_interval_seconds`。仍有 30 秒绝对下限且不可超出官方要求。配置项不是授权证明；不提供高频脉冲或规避限流能力。403/429 停止。
- **启动前预检**：查询规则非法时会给出本地阻止提示；离线未配目标课程不影响离线使用。
- **错误表格排除**：配置了 `protocol.table_marker` 时，只解析唯一匹配起始 `<table ...>` 标签的表格，避免误从页面其他表格读取课程余量。检测到没有目标表或多张同标识表时停止，不假定余量。
- **方案持久化**：新时长参数可跟随方案保存与恢复，旧方案缺少该参数时回退到 480 分钟。

## 验收范围和边界

- 99 项**纯离线** Python 单元测试通过；其中 12 项是本轮新增测试。
- 本地 Python GUI 冒烟检测通过（依赖 Xvfb/Tk）；不代表 Win10/11 实际显示或安装通过。
- 没有访问学校、重放 HAR、发送选课请求、绕过验证码或服务器频率限制。
- 没有真实课程目录或余量字段验收；`protocol.verified` 模板仍为 `false`。
- **V4.6 基线已通过 PR #1 合入 main；V5.0 的集成修改正在 PR #3 审查。** Windows 原生测试和打包结果以 PR #3 的 Actions 为准，未完成真实学校接口验收，也没有发布正式 V5.0 EXE。
