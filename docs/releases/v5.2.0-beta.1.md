# KingoAssistant v5.2.0-beta.1 · Windows 密集工作台预览版

发布日期：2026-11-20

## 本次发布

- 以 PR #89 的密集 Win32/Tkinter 工作台作为唯一正式 Windows UI 方向；顶部 34px 紧凑命令条、两个可见页签「选课工作台」「工具与日志」、白色表格、底部固定定时计划与提交状态区域。
- 保留主线进程内纯 HTTP 登录、只读学校查询、离线课程方案、调度状态机、官方结果确认与证据门禁等已有代码；未引入浏览器混合执行或 Tauri sidecar。
- 旧 React + Tauri Lite 计划（PR #47）已取消，旧 LightC 侧栏方案不再使用。
- Windows CI 运行 Python 离线单测、源码自检、PyInstaller 单文件构建和打包后实际 Tk 界面冒烟测试，生成 SHA-256 校验文件及构建验证 JSON。

## 重要功能边界

- 本版本为 **Beta 预览版，不是已验收的正式抢课工具**。华水本人真实登录、实时教学班与余量、正式提交协议、官方结果回读的端到端实机验收尚未完成。
- 正式自动提交仍为禁用状态；不会因升级 UI 或发行新版本而默认开启，也不声称成功抢课。
- 已知的学校数据需要本人账号按官方许可验证，任何本机演示不表示真实接口可用。

## 安装与校验

- 运行 Windows 10/11 便携版 EXE，无需安装 Tauri 或浏览器插件。
- 下载版本化 EXE 或便携 ZIP，使用附带的 SHA256 文件核对一致性。
- GitHub Actions 的离线通过只能保证构建、窗口控件与模拟环境检查，不能替代本人真实学校流程验收。
