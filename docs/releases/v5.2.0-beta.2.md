# KingoAssistant v5.2.0-beta.2 · Windows 工作台预览版

## 界面更新

- 主窗口上方显示课程筛选和结果，下方并排显示目标任务、运行日志与执行计划。
- 查询结果可按课程名、编号和教师筛选。选中的课程可带入目标编辑器，教学班编号需要独立确认。
- 账号与登录、执行记录和抢课设置各有独立页签，可在应用内填写账号密码、导出本次运行日志和编辑本机计划。
- 统一使用微软雅黑 UI 和灰白配色，修复了高 DPI 下执行按钮、配置编辑器保存按钮的显示问题。

## 下载与验证

下载 Windows 10/11 便携 EXE，或解压便携 ZIP 后运行其中的 EXE。SHA-256 校验文件与构建验证记录随发布提供。

验证覆盖离线单元测试、Windows 窗口冒烟和打包后 EXE 自检。真实教务登录与查课未做实机验收。扫码、跨次账号保存与正式自动提交仍待接入。
