# 本地 HAR 审计与证据对照（Windows V4.7）

**离线分析，不自动验证教务接口。**

## 使用方式

1. 打开 KingoAssistant Windows → **离线工具** → **本机 HAR 结构检查（脱敏统计）**。
2. 选择本人正常使用喜鹊儿/华水网页后合法导出的 HAR。文件只在本机读取，不上传或重放。
3. 界面仅显示三类统计：学校官方 HTTPS 请求数、喜鹊儿统一业务入口请求数、华水课表 JSON 结构匹配数和“当前时间不是有效的选课时间区段”的出现次数。
4. 若要人工检查“官方页面余量 vs 只读响应候选字段”，先按照 [课程目录验收规程](catalog-readonly-verification.md) 在本机整理**脱敏、匿名**的 JSON，然后使用 **离线工具 → 选课目录证据对照（离线 JSON）**。
5. 证据工具输出“待人工复核”仅说明输入样例的匿名数值一致，**不能说明实际接口已验证、余量真实或选课成功**。

## 安全与边界

- 工具**不建立 HTTP 连接**、不读取账号来登录、不解析签名、不重放任何 POST。
- 日志和弹框仅输出统计数量或固定原因代码，不显示完整 URL、学生数据、Cookie、Token、课名、响应正文。
- 原始 HAR 可能含个人会话和班级信息：请只在本人设备保存，不要上传到 GitHub、发到群里或附在公开 Issue。
- 识别个人课表结构成功 ≠ 课程目录已经接入。现有 `protocol.verified` 应保持 `false`，直到完成正式选课开放时段的人工核验。
