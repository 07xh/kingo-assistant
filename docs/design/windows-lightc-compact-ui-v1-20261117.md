## 这一版是真实可见的 UI 改版

前七批清理侧重代码结构，虽然 `windows_gui.py` 已变得更易维护，
但用户在 EXE 中仍看到原来的 Tkinter 顶部选项卡和密集按钮。
本轮直接修改 **真实运行界面**，而不是仅替换 Python 模块。

目标是更紧凑、更清楚的桌面操作层级，**借鉴 LightC-UI 的视觉组织**
而非宣称已复制其原生/动效系统。当前仍使用 Python Tkinter/ttk，
不引入 WebView、额外 JS 容器或另一套进程，以保障现有真实登录
与学校只读查询适配器不回退。

## 视觉基准

- **左侧窄导航**：深色 98px 侧边栏，K 品牌识别，以及「首页 / 官网 / 工具」
  三个入口。活动项采用蓝色高亮；标签含图形字符；最低必要信息留在底部。
- **主内容区**：浅灰画布、白色卡片和更明显的页面标题，
  控件文字、行高、留白、表头风格统一。
- **主按钮**：「填写 / 修改目标课程」「在 EXE 登录本人教务账号」
  「开始查询课程余量」使用明显的蓝色主操作样式。
  其他操作保持次级样式，不能把禁用的自动提交按钮视觉上误当成可用主操作。
- **表格**：32px 高度的行、灰蓝表头、淡蓝选中态；原课程列、
  双击复制、滚动条与真正的数据展示均不变。
- **页面导航**：`ttk.Notebook` 仍然是唯一页面选择源；
  只是通过 ttk 样式隐藏旧顶部选项卡，由左侧导航按钮触发原有
  `Notebook.select()`。菜单和旧逻辑的程序化导航仍自动同步高亮，
  防止维护两套当前页状态。
- **尺寸**：默认 1210×820，最小 1020×680，兼顾 Windows 桌面与
  侧边导航宽度。无法使用 Tk 原生组件真实实现复杂液态玻璃动效，
  本版不宣称视觉或控件行为与 LightC-UI 完全一致。

## 文件与兼容性

新增 `windows_visual_shell.py` 负责调色板、ttk 样式、
侧边栏构建和导航高亮。原 `Application._build` 仅将三个既有
`build_*_page(app)` 页面放入视觉外壳。
**原 `Application` 继续拥有全部状态变量、Tk 控件引用、
背景任务、事件总线、日志、会话状态和业务函数。**

不改动 `core/` 学校协议、S202 表单初始化和 GBK 请求、
成绩/课表/课程读取、只读监测、请求预算、验证码、配置持久化、
预约功能或后端构建约束。

## 回归与真实预览

- 无显示器回归：侧边栏三目的地回调和选中态、旧 Notebook 隐藏样式、
  主要按钮与主题配置不触发网络。
- 真实 Tk：在 `tests/smoke_gui.py` 验证侧栏、按钮高亮和
  菜单/程序化导航；保留原设置编辑、课程列表、离线演示、
  自动提交禁用态和完整关闭测试。
- PyInstaller 后验证：`run_packaged_gui_smoke` 额外验证侧栏、
  工具导航和禁用的提交入口，必须全部通过才上传 Windows EXE。
- 可选截图：`tests/export_visual_preview.py` 仅用虚构本地模板在
  Windows CI 上打开真实 Tk 界面并尝试截取
  `KingoAssistant-UI-preview.png`。部分 GitHub runner 不支持可交互屏幕，
  因此截图失败不代表 EXE 构建失败。截图属于**真实界面外观预览**，
  不代表学校接口测试成功。
