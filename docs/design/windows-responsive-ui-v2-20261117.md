## 核验基准

以 `main` 最新版 `196d516d8c0e00703f47c60c4b876a89f6455bc9` 的 Tk
界面为基础。前一版 V1 已真正增加深色左侧导航、浅色内容区、蓝色主操作按钮，
但实机截图显示低分辨率屏幕上首页第 3 步已接近窗口底部，课程列表和工具区很难看到。
这不是拆分 Python 文件能解决的问题。

## V2 实际改造

1. 首页与「工具与日志」分别使用 **Canvas + ttk.Scrollbar** 的纵向滚动容器；
   Notebook 下原来的 `tab_home` 与 `tab_tools` 页面对象仍是真实导航目标。
   业务控件仍由 `Application` 拥有，课程表与日志不被重建/复制。
2. 滚轮在只读文案、按钮与卡片等无独立滚动行为的区域控制外层页面，
   在 `Treeview`、日志 `Text`、输入框及滚动条上不劫持原有滚动行为。
   同时支持 Windows `MouseWheel` 和 Linux `Button-4/5`。
3. 窄窗口下导航栏 98px → 80px，页头改短，底部状态栏按内容宽度换行；
   低于 660px 高时隐藏次级长说明，优先给实际操作空间。
4. 原先固定 920/670px 的状态文案换行宽度改为随窗口自适应，
   放大窗口时恢复此前宽度，避免截断状态或永久变成窄文本。
5. 程序默认尺寸 1100×740，最小尺寸 880×560，适配小屏 Windows
   窗口。真实内容仍按原先三步骤和只读门禁排列，未改变按钮文案或业务逻辑。
