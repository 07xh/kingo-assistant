# KingoAssistant Windows · 界面使用说明

> **历史 UI 记录，不再作为当前实施方案。** 2026-11-20 纯接口架构已取消“手动官网备用”、浏览器预约及浏览器登录混合路线；这些旧页面仅在旧版本源码/截图中可见，必须逐项清理。当前唯一规范：[纯接口执行架构](pure-api-execution.md)。

从本次界面重构开始，主界面只有三个明确的入口：**① 选课首页**、**② 手动官网备用**、**③ 工具与日志**。这只是信息架构与交互整理，不意味着真实华水接口已经验收。

## ① 选课首页：普通使用

- **第 1 步：填写 / 修改目标课程**（已可用，本地数据）。配置课程、代码、教学班、备选志愿；保存不等于官方选课。
- **第 2 步：在软件内登录 / 检查登录与课程数据**（代码框架存在，华水真实身份/课程接口待验收）。这一部分由 EXE HTTP 客户端尝试，并不自动操纵浏览器。若协议没有核验，安全停止，不应当当作软件故障或登录成功。
- **第 3 步：开始查询课程余量**（只读，学校接口协议与本人授权会话满足门禁后才能使用）。不发送选课 POST。
- **自动提交（暂不可用）**：学校专用提交适配器尚未接通，按钮禁用。不要将离线调度测试当作真实抢课结果。
- **目标课程列表**：默认模板课程为“仅示例 · 未连接”；真实课程在尚未查询时标为“未查询”。这个状态不是已选成功，也不代表剩余名额为 0。
- **运行状态**：任何页面底部都能看见，不再依赖切到日志页查看反馈。
- **功能说明**：右上角，解释各功能是做什么的和是否可用。

## ② 手动官网备用

这里只有手动打开华水教务官网、复制所选课程代码后打开官网、预约按时打开官网等功能。打开网页、登录、选课以及提交仍由本人完成。这和 EXE 内直接向教务 API 提交是不同的能力，不要混淆。

## ③ 工具与日志

仅供离线分析/调试：HAR 认证链路识别、HAR 课程结构分析、课程目录证据对照、离线 HTML 演练、虚构示例、离线调度测速、学校官方入口可达性检测、自动选课计划的**本地字段预检**、高级 YAML 设置、导出本地运行日志。工具页的“检测成功”不代表已拿到学校真实课程名额或已提交。

## 保留的功能与安全门禁

- 保留原有课程/志愿编辑、方案管理、后台线程、系统托盘、定时执行接口、登录核验、只读监测、手动官网备用、HAR/HTML 工具和运行日志。
- 不会在界面重构期间修改教务协议、登录验证、选课提交逻辑及限流参数。
- 学校真实自动提交继续禁用，不新增模拟成功数据。
- 打包后需要通过 Windows 单测、EXE 离线自检和 Tk GUI 冒烟测试，重点确认各标签页、工具按钮和状态栏均正常。

## 本轮验收重点

- 程序启动后默认显示“① 选课首页”，而非混杂的按钮工具栏。
- 首页明确区分 **本地可用**、**真实接口待核验**、**自动提交不可用**。
- 点击“② 手动官网备用”前，不显示手动预约组件；不允许把打开浏览器作为自动执行。
- “③ 工具与日志”能完整访问所有原有诊断功能，不丢失日志。
- 从任何页面仍能看到底部运行状态；未验证接口时不会访问学校或弹出需要输入密码的窗口。
